# 🌿 EduBalance

**Balance Your Mind. Balance Your Studies.**

EduBalance is a **student wellness platform** built with ASP.NET Core MVC that helps students maintain a healthy balance between academics and personal wellbeing. Track your mood 😊, manage stress 😵‍💫, organise schedules 📅, and monitor your study-life balance 📊 — all in one place.

---

## Why EduBalance?

Student life can become overwhelming. EduBalance was designed to help students:

- Understand their emotional wellbeing
- Build healthier study habits
- Manage stress effectively
- Improve productivity without burnout

Because academic success should never come at the cost of mental wellness 🌱

---

## Features

### 🔐 Authentication System
- Student registration
- Secure login/logout
- ASP.NET Identity integration
- User-specific data protection

### 📊 Smart Dashboard
A central dashboard giving students a quick overview of their wellness journey:
- Total mood logs
- Stress check-ins count
- Weekly study hours
- Wellness score
- Mood trend charts
- Study balance pie charts

### 😊 Mood Tracking
- Create mood logs
- Add personal notes
- Edit entries
- View mood history
- Delete logs

### 📅 Schedule Management
- Subject schedules
- Study locations
- Time management
- Schedule editing & deletion

### 😵‍💫 Stress Check-Ins
- Stress scale (1–10)
- Cause tracking
- Stress history
- Detailed check-ins

### ⚖️ Study-Life Balance
- Study hours
- Break hours
- Productivity balance
- Wellness metrics

## Getting Started

1. **Clone the repository.**
2. **Open the project** in Visual Studio 2022+ or VS Code.
3. **Configure the database connection** in `appsettings.json`.
4. **Run database migrations**:
   ```bash
   dotnet ef database update
   ```
5. **Start the application**:
   ```bash
   dotnet run
   ```
6. **Access the app** at `https://localhost:7134`.
